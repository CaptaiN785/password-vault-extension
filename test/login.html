Password Vault — browser fixtures

Save a login for localhost first (open a fixture, type credentials, press the save shortcut). Then press the fill shortcut on each page below. Each fixture isolates one thing that commonly breaks autofill.

  • 1. Plain form

    The baseline. A real form with autocomplete hints.

  • 2. React-style tracked inputs

    Proves the fill goes through the native value setter, not a plain assignment.

  • 3. Open shadow root

    Inputs inside a web component, invisible to a normal querySelectorAll.

  • 4. Login inside an iframe

    The picker and the fill must be routed to the child frame.

  • 5. Three forms on one page

    Fill and save must target the form your caret is in, not the first one found.
