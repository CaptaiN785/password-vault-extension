Welcome

  3. On a login page, press the fill shortcut — or just click into the username box and pick from the list.

Shortcuts

Locking

The vault always locks when Chrome quits.

Touch ID

Unlock with your fingerprint instead of typing your master password. Your master password keeps working and stays the only way to recover the vault.

Security check

Looks for reused and weak passwords. Nothing leaves this computer.

Import

This extension cannot read Chrome's built-in password manager — the browser gives extensions no access to it. Export your passwords from Chrome first (Settings → Autofill and passwords → Google Password Manager → Settings → Export passwords), then load the file here. Delete the file afterwards: it is not encrypted.

Backup

A backup file is encrypted and is useless without your master password. Restoring replaces everything currently in the vault.

Change master password

Changing it also turns off Touch ID, so enrol again afterwards.

    How your data is kept

    • Your vault is encrypted on this computer and is never sent anywhere.
    • Your master password is never stored. If you forget it the vault cannot be recovered, so keep a backup.
    • While the vault is unlocked, anyone using this computer can read your saved logins. Lock it when you step away.
